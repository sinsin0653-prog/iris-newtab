# 講義ノート（kogi-note）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 講義の音声・メモ・レジュメから全文の文字起こしと要約を作る、自分専用の Web アプリを `kogi-note/` に作る。

**Architecture:** 1 つの Cloudflare Worker が、静的な画面（`public/`）と JSON API（`/api/*`）と 1 分ごとの見回り（`scheduled`）を受け持つ。データは D1、写真と PDF は KV、音声は Gemini Files API に一時的に置く。AI への依頼はすべて `src/ai/index.js` の差し替え口を通す。

**Tech Stack:** JavaScript（ES modules、TypeScript なし）、Cloudflare Workers / D1 / KV / Cron、Gemini REST API、Vitest 4.1 + `@cloudflare/vitest-plugin`、Playwright（環境にあるものを使う）

**Spec:** `kogi-note/docs/superpowers/specs/2026-10-28-kogi-note-design.md`

## Global Constraints

- すべてのファイルは `kogi-note/` の中に置く。iris-newtab のほかのファイルは変えない。コマンドは `kogi-note/` で実行する。
- Node 22。依存は `wrangler@^4`、`vitest@~4.1.0`、`@cloudflare/vitest-plugin@^1.4.9` だけ（devDependencies）。この環境の npm は peer 依存の解決で落ちるので、`kogi-note/.npmrc` に `legacy-peer-deps=true` を書く。
- `compatibility_date` は `"2026-08-01"`（手元の workerd が 2026-08-22 までしか知らない）。
- 画面はフレームワークなし。画面に出す文字は `textContent` だけで入れ、`innerHTML` に利用者や AI の文字を入れない。
- 画面の文言は日本語。iris-newtab と同じく、コメントは日本語で短く。
- 秘密の設定：`APP_PASSWORD`、`SESSION_SECRET`、`GEMINI_API_KEY`。ふつうの設定：`GEMINI_MODEL`、`GEMINI_BASE_URL`（既定 `https://generativelanguage.googleapis.com`）、`SEGMENT_SEC`（既定 `1800`）、`SEGMENT_INTERVAL_MS`（既定 `65000`）。
- 区間は 30 分（1800 秒）、区間の間は 65 秒以上あける。音声の長さが不明なら 120 分とみなす。
- 写真は長い辺 2000px・JPEG 品質 0.85 に縮める。PDF は 20MB（20971520 バイト）まで、写真は 5MB まで、音声は 2GB（2147483648 バイト）まで。添付は 1 授業 20 個まで。
- KV の上限 1GB（1073741824 バイト）、8 割で注意。
- 音声のかけらは 16MiB（16777216 バイト）。Gemini が単位（granularity）を返したら、その倍数で 16MiB 以下の最大の値にする。
- クッキー：名前 `kogi_session`、`HttpOnly; Secure; SameSite=Strict; Path=/`、30 日。値は `<期限ミリ秒>.<HMAC の16進>`。
- ログインのロック：15 分以内に 5 回まちがえたら 15 分ロック。
- データを変えるリクエスト（POST・PUT・PATCH・DELETE）は `X-Kogi: 1` ヘッダーが必要。なければ 403。
- エラーの返し方は全 API で共通：`{ "error": { "code": "<英字>", "message": "<日本語>" } }`。
- 時刻はすべてミリ秒の整数。処理の関数は `now` を引数で受け取る（テストで時刻を決めるため）。`Date.now()` は `src/index.js` だけで呼ぶ。
- 音声の期限：`audio_expires_at - now < 600000`（10 分）なら期限切れとみなす。
- 作業中の印（lease）は 10 分（600000 ミリ秒）。

### 設計書から決め直したこと

- `lectures` に `rate_limit_count INTEGER NOT NULL DEFAULT 0` を足す（429 の待ち時間を 2・4・8…分と伸ばすために回数が要る）。
- 一時的なエラーの待ち時間は「1 回目 2 分、2 回目 4 分、3 回目でエラー」にする（設計書 6.1 の「8 分」は使わない。3 回目で止まるので）。
- 設計書 11 章の「区間の間隔と長さを設定で変えられる」を `SEGMENT_SEC` と `SEGMENT_INTERVAL_MS` で実現する。e2e では間隔を 0 にする。
- e2e で Gemini のニセモノにつなぐため、`GEMINI_BASE_URL` を設定にする。
- 添付は 1 授業 20 個まで（見回り 1 回のサブリクエスト上限 50 に収めるため）。写真は 5MB まで。

## Review Focus

1. **音声の長さが読めない（m4a で `duration` が `Infinity` や `NaN` になる）** → 120 分とみなして 4 区間で進み、余った区間は空になる。Task 11 の `normalizeDuration` のテストと、Task 8 の `duration_sec: null` のテストで押さえる。
2. **処理中に「やり直す」「要約を作り直す」を連打する** → 2 回目以降は 409 で、処理が二重にならない。Task 4 のテストで押さえる。
3. **アップロードの途中で画面を閉じ、あとで音声を入れ直す** → `audio/start` をもう一度呼ぶと、古い Gemini のファイルを消し、offset 0・区間なしからやり直す。Task 7 のテストで押さえる。
4. **Gemini が `[MM:SS]` のない行や `[1:15:30]` 形式の時刻を返す** → 文字起こしは捨てずに表示し、時刻のリンクは 60 分超えも `H:MM:SS` も扱える。Task 11 の `parseTime` / `parseTranscript` のテストで押さえる。
5. **要約の配列が空、または `time` が文字起こしのどの行にも合わない** → 画面が落ちず、いちばん近い前の行に飛ぶ（なければ先頭）。Task 6 の `validateSummary`（空配列 OK）と Task 11 の `nearestLineIndex` のテストで押さえる。

import { env } from 'cloudflare:test';
import { beforeEach, it, expect } from 'vitest';
import { resetDb, makeRequest } from './helpers.js';
import { login, logout, isLoggedIn, checkMutation } from '../src/auth.js';

const T0 = 1_800_000_000_000;
const cookieOf = (res) => res.headers.get('set-cookie').split(';')[0];
beforeEach(() => resetDb(env));

it('correct password sets a 30-day session cookie', async () => {
  const res = await login(makeRequest('/api/login', { method: 'POST', json: { password: 'test-pass' } }), env, T0);
  expect(res.status).toBe(200);
  const sc = res.headers.get('set-cookie');
  expect(sc).toMatch(/^kogi_session=\d+\.[0-9a-f]+;/);
  for (const part of ['HttpOnly', 'Secure', 'SameSite=Strict', 'Path=/']) expect(sc).toContain(part);
  expect(await isLoggedIn(makeRequest('/api/me', { cookie: cookieOf(res) }), env, T0 + 29 * 86400_000)).toBe(true);
  expect(await isLoggedIn(makeRequest('/api/me', { cookie: cookieOf(res) }), env, T0 + 31 * 86400_000)).toBe(false);
});

it('wrong password is 401 and is recorded', async () => {
  const res = await login(makeRequest('/api/login', { method: 'POST', json: { password: 'nope' } }), env, T0);
  expect(res.status).toBe(401);
  expect((await res.json()).error.code).toBe('wrong_password');
});

it('locks after 5 failures within 15 minutes, even for the right password', async () => {
  for (let i = 0; i < 5; i++) await login(makeRequest('/api/login', { method: 'POST', json: { password: 'x' } }), env, T0 + i);
  const locked = await login(makeRequest('/api/login', { method: 'POST', json: { password: 'test-pass' } }), env, T0 + 10);
  expect(locked.status).toBe(429);
  const later = await login(makeRequest('/api/login', { method: 'POST', json: { password: 'test-pass' } }), env, T0 + 15 * 60_000 + 10);
  expect(later.status).toBe(200);
});

it('tampered cookie and cookie from an old password are rejected', async () => {
  const res = await login(makeRequest('/api/login', { method: 'POST', json: { password: 'test-pass' } }), env, T0);
  const c = cookieOf(res);
  expect(await isLoggedIn(makeRequest('/', { cookie: c.slice(0, -1) + (c.endsWith('0') ? '1' : '0') }), env, T0)).toBe(false);
  expect(await isLoggedIn(makeRequest('/', { cookie: c }), { ...env, APP_PASSWORD: 'changed' }, T0)).toBe(false);
  expect(await isLoggedIn(makeRequest('/'), env, T0)).toBe(false);
});

it('logout clears the cookie', () => {
  expect(logout().headers.get('set-cookie')).toContain('Max-Age=0');
});

it('mutations need X-Kogi', () => {
  expect(() => checkMutation(makeRequest('/api/subjects', { method: 'POST', json: {}, headers: { 'X-Kogi': '' } }))).toThrow(expect.objectContaining({ status: 403 }));
  expect(() => checkMutation(makeRequest('/api/subjects', { method: 'POST', json: {} }))).not.toThrow();
  expect(() => checkMutation(makeRequest('/api/subjects', { headers: { 'X-Kogi': '' } }))).not.toThrow();
